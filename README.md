# Calculator Web App

A simple web-based calculator built with **HTML**, **CSS**, and **JavaScript**.  
It supports basic arithmetic operations, keyboard input, a light/dark theme toggle, and a calculation history.

---

## 🚀 Features

- Basic math operations: `+`, `−`, `×`, `÷`
- Real-time display updates
- Keyboard support (numbers, operators, Enter, Backspace, Escape)
- Light / Dark theme toggle
- Calculation history (stores last 10 results)
- Clean and responsive UI
